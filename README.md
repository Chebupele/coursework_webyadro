# Gadget Hub

Учебный интернет-магазин гаджетов для курса веб-разработки. Фронтенд написан на React и запускается через Vite, сервер работает на Node.js и Express. Сейчас доступны четыре страницы-заготовки, общая навигация и проверка связи с API. Возможности магазина описаны в разделе [«Дальнейшая разработка»](#дальнейшая-разработка).

## Быстрый старт

Понадобятся Node.js 22.12+ и npm. Откройте два терминала в корне репозитория.

**Терминал 1 — API**

~~~sh
cd backend
npm ci
npm run dev
~~~

**Терминал 2 — фронтенд**

~~~sh
cd frontend
npm ci
npm run dev
~~~

Откройте [http://127.0.0.1:3000/](http://127.0.0.1:3000/). Для остановки нажмите `Ctrl+C` в каждом терминале. `npm ci` нужен при первом запуске и после изменений соответствующего `package-lock.json`.

## Структура и архитектура

| Путь | Назначение |
| --- | --- |
| [frontend/src/pages/](frontend/src/pages/) | Главная, вход, каталог и корзина |
| [frontend/src/components/](frontend/src/components/) | Общая шапка, навигация и подвал |
| [frontend/src/styles/](frontend/src/styles/) | Базовые стили и подключение Rubik |
| [frontend/public/assets/](frontend/public/assets/) | Изображения товаров, иконки и шрифт |
| [frontend/src/api/client.js](frontend/src/api/client.js) | Общий клиент для запросов к `/api/v1` |
| [backend/src/](backend/src/) | Запуск Express, настройка приложения и серверные маршруты |
| [backend/data/goods.json](backend/data/goods.json) | Начальный набор из 32 товаров |
| [api/openapi.yaml](api/openapi.yaml) | Контракт REST API |

В браузере запросы идут на тот же адрес, с которого загружен фронтенд. Vite проксирует `/api/v1` на Express. При замене сервера достаточно реализовать тот же контракт и поменять адрес прокси.

## Настройки окружения

При стандартных портах файлы `.env` необязательны. Для изменения настройки скопируйте `.env.example` в `.env` в соответствующей папке и перезапустите сервер.

| Папка | Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- | --- |
| `backend/` | `PORT` | `8080` | Порт Express на `127.0.0.1` |
| `frontend/` | `API_TARGET` | `http://127.0.0.1:8080` | Адрес API для прокси Vite |

Если меняете порт API, обновите обе настройки. В `API_TARGET` указывайте только схему, адрес и порт. Путь `/api/v1` прокси передаёт сам.

## Маршруты и API

| Путь в браузере | Страница |
| --- | --- |
| `/` | Главная |
| `/login` | Вход |
| `/catalog` | Каталог |
| `/cart` | Корзина |

На текущем этапе все четыре маршрута открываются напрямую. Из API доступен `GET /api/v1/health`. Операции сессии, товаров и заказов описаны в [OpenAPI](api/openapi.yaml) и помечены `x-status: planned`.

## Проверка и сборка

1. Откройте все четыре страницы напрямую и через навигацию. На каждой должен появиться соответствующий заголовок.
2. При запущенных серверах выполните запросы ниже. Оба должны вернуть HTTP 200 и `{"status":"ok"}`. В Windows PowerShell используйте `curl.exe`.

   ~~~sh
   curl -i http://127.0.0.1:8080/api/v1/health
   curl -i http://127.0.0.1:3000/api/v1/health
   ~~~

3. В папке `frontend` выполните `npm run build`. Результат появится в `frontend/dist/`. Для запуска Express без автоматического перезапуска используйте `npm start` в папке `backend`.

## Работа с данными

В `backend/data/goods.json` у каждого товара два поля, `id` и `name`. Изображению соответствует файл `frontend/public/assets/goods/image_<id>.png`. При добавлении позиции используйте уникальный числовой ID и положите изображение с тем же номером.

## Если запуск не работает

| Симптом | Что проверить |
| --- | --- |
| Express пишет `.env not found. Continuing without it.` | При запуске с настройками по умолчанию это ожидаемое сообщение. |
| `npm ci` или Vite сообщает о несовместимой версии Node.js | Сверьте вывод `node --version` с требованиями выше. |
| Порт `3000` или `8080` занят | Остановите ранее запущенный сервер. Для Express можно выбрать свободный порт через `PORT` и обновить `API_TARGET`. |
| Прямой запрос к API не проходит | Проверьте вывод Express и адрес в настройке `PORT`. |
| Прямой запрос проходит, а запрос через Vite падает | Сверьте `API_TARGET` с адресом запущенного Express и перезапустите Vite. |

## Дальнейшая разработка

1. Добавить вход, серверную сессию, защиту маршрутов и карусели главной.
2. Дополнить данные о товарах, реализовать выдачу каталога, карточки, фильтры, сортировку и пагинацию.
3. Реализовать корзину в `localStorage`, оформление и историю заказов. Сохранять заказы в `backend/data/orders.json`. Этот файл исключён из Git.
4. Пройти сценарий от входа до появления заказа в истории, проверить сохранение после перезапуска и сверить интерфейс с макетами.
